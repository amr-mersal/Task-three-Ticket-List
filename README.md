## Ticket Filter App (React)

This is a simple ticket filter application built using React. It allows you to filter tickets based on their status and search by ticket ID.

##  Features

-  filter tickets based on their status
-  search by ticket ID
 ##  Technologies Used
- React 
- useState (React hook for state management)
- bootstrap

##  Getting Started

###  Clone the repository

```bash
git clone https://github.com/amr-mersal/Task-three-Ticket-List.git
cd Task-three-Ticket-List
npm install
npm run dev
```
